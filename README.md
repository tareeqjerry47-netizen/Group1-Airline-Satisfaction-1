Project Overview
This project investigates whether the average inflight service rating is significantly lower than the company target of 4.0 on a 0.5 rating scale
Statistical Methods
One sample students t test 
descriptive statistics
wilcoxon rank test fro sensitivity analysis n
normality assessment and plots 
Main findings
sample size:103904
Mean inflight service rating:3.64
standard deviation:1.18
t statistic:-98.6
degrees of freedom: 103,903
p-value:less than .001
cohens d:0.306 
the results indicate that the average inflight service rating is significantly below the target of 4.0
